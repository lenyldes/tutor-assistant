# Демонстрационные файлы

Все имена и содержимое синтетические. Файлы в корне этого каталога нужны готовым сценариям на главной странице; не перемещайте их без одновременного изменения ссылок в UI. Дополнительные образцы лежат в `names/` и `formats/`. Через ручную форму можно выбрать сразу несколько файлов из разных папок.

Обозначения для таблицы:

- **Д** — `дневник_наблюдений.xlsx`;
- **О** — `отчёт_о_занятии.pdf`;
- **Р** — `обратная_связь_родителя.docx`;
- **З** — `заключение_специалиста.png`.

| Проверка | Тип записи и файлы | Ожидаемый результат |
| --- | --- | --- |
| Полный день | `daily`: Д, О, Р | `complete`, замечаний нет |
| Полная неделя | `weekly`: Д, О, Р, З | `complete`, замечаний нет |
| Не хватает обратной связи | `daily`: Д, О | `incomplete`, одна ошибка |
| Не хватает заключения | `weekly`: Д, О, Р | `incomplete`, одна ошибка |
| Нераспознанное имя | `daily`: Д, О, Р, `scan_0041.jpg` | `complete`, одно предупреждение |
| Запрещённый формат | `weekly`: Д, О, Р, `заключение_специалиста.exe` | `incomplete`, предупреждение о формате и ошибка о заключении |
| Дублирование категории | `daily`: Д, `names/ДНЕВНИК-НАБЛЮДЕНИЙ_15-03.PDF`, О | `incomplete`, ошибка об обратной связи |
| Регистр и разделители | `weekly`: `names/ДНЕВНИК-НАБЛЮДЕНИЙ_15-03.PDF`, О, `names/обратная связь родителя.DOCX`, `names/заключение-специалиста.PNG` | `complete`, замечаний нет |
| Двойное расширение | `daily`: `formats/дневник_наблюдений.pdf.exe`, О, Р | `incomplete`, предупреждение о формате и ошибка о дневнике |
| Другой запрещённый формат | `daily`: `formats/дневник_наблюдений.csv`, О, Р | `incomplete`, предупреждение о формате и ошибка о дневнике |
| Без расширения | `daily`: `formats/дневник_наблюдений`, О, Р | `incomplete`, предупреждение о формате и ошибка о дневнике |
| Пустой PDF | `daily`: Д, `formats/отчёт_о_занятии_пустой.pdf`, Р | `incomplete`, предупреждение о пустом файле и ошибка об отчёте; пустой файл остаётся в результате с размером 0 КБ |
| Ровно 20 МБ | `daily`: `size/дневник_наблюдений_20МБ.pdf`, О, Р | `complete`, предупреждения о размере нет |
| Больше 20 МБ на байт | `daily`: `size/дневник_наблюдений_20МБ_плюс_1.pdf`, О, Р | `incomplete`, предупреждение о размере и ошибка о дневнике |

Оба файла из `size/` создаются командой `python3 demo_files/create_size_samples.py` из корня проекта. Это корректные PDF с точным размером 20 МБ и 20 МБ + 1 байт. Их не хранят в Git, чтобы не увеличивать репозиторий на 40 МБ. Генератор можно запустить без сторонних зависимостей.

Для проверки одновременного нарушения формата и размера скопируйте файл `size/дневник_наблюдений_20МБ_плюс_1.pdf` с расширением `.exe` и отправьте его вместо Д вместе с О и Р. Ожидаются два предупреждения для файла и ошибка о дневнике.

Ошибки HTTP 400 (отсутствует поле `files`) и 422 (`record_type=monthly`) нельзя воспроизвести одним набором файлов. Для них используйте `/docs` или запросы к API. Неуспешный запрос не должен создавать запись в истории. После любого успешного POST проверьте результат через `GET /api/checks/{id}` и строку в `GET /api/checks`; у всех результатов поле `extracted` равно `{}`.
