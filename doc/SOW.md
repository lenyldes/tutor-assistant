# Тестовое задание для Backend-разработчика

## Тестовое задание

**Задача**: реализовать REST API сервис проверки дневных записей наблюдений с сохранением истории в PostgreSQL.

### Требования к API и логике проверок

- Реализовать эндпоинт `POST /api/checks`: принимает файлы (`multipart/form-data`) и тип записи (`daily` / `weekly`), запускает проверку, возвращает результат и сохраняет его в БД.
- Реализовать `GET /api/checks` — список всех проверок (`id`, дата, тип записи, статус, количество материалов).
- Реализовать `GET /api/checks/{id}` — полный результат конкретной проверки.
- Определять тип материала по имени файла (дневник наблюдений, отчёт о занятии, обратная связь родителя, заключение специалиста) и проверять комплектность записи: для `daily` обязательны дневник наблюдений, отчёт о занятии, обратная связь родителя; для `weekly` — все четыре, включая заключение специалиста. Анализ по количеству и по паттерну имени.
- Добавить проверки: недопустимый формат файла (только PDF, DOCX, XLSX, JPG, PNG), размер файла более 20 МБ, нераспознанное имя файла — предупреждение уровня warning.
- Итоговый статус: `complete` (нет нарушений), `incomplete` (есть хотя бы одна ошибка), `check_in_progress`.
- Покрыть тестами через `pytest` логику определения типа материала и формирования итогового статуса — минимум 5 тест-кейсов.
- Весь проект должен подниматься одной командой `docker compose up` — предоставь `Dockerfile` для сервиса и `docker-compose.yml` с сервисом PostgreSQL.
- Репозиторий должен содержать `README.md`: как запустить, как запустить тесты, описание переменных окружения из `.env.example`.

```json
{
  "check_id": "abc123",
  "status": "incomplete",
  "status_label": "Запись неполная — нельзя передавать в анализ",
  "reason": "Отсутствует обратная связь родителя за день.",
  "issues": [
    { "level": "error", "message": "Отсутствует обязательный материал: обратная связь родителя" },
    { "level": "warning", "message": "Не удалось определить тип материала: «scan_0041.jpg»" }
  ],
  "documents": [
    { "name": "дневник_наблюдений_15-03.xlsx", "detected_type": "observation_diary", "size_kb": 142 }
  ],
  "extracted": {
    "child_code": "Р-014",
    "tutor": "Иванова А. С.",
    "date": "15.03.2025",
    "observed_blocks": "эмоции, коммуникация, поведение, сон"
  },
  "checked_at": "2025-03-15T14:32:00Z"
}
```

### Требования к реализации

Требования к реализации: конфигурация через `.env`, корректные HTTP-статусы (400, 404, 422), валидация через Pydantic, миграции через Alembic.
